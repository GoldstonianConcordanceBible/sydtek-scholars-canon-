# sydtek-scholars-canon-
This repository contains the **SydTek Scholars Canon**: the K–12 covenant-school blueprint and accreditation foundation for SydTek Scholars (Mt. Gilead, NC).

## What’s inside
- Canon book (mission, creed, governance, academic doctrine, accountability)
- Policies pack (safeguarding, privacy, AI integrity, AUP, admissions/tuition, etc.)
- Handbooks (student/family/faculty templates)
- Curriculum scope & sequence + Hebrew thread
- Assessment/outcomes + portfolio doctrine
- Accreditation self-study outline + evidence index
- **GemachAI Prompt Supplement** (copy/paste prompts for every chapter)

## Public accountability
This repo is intended to be **public** for transparency and accountability.
